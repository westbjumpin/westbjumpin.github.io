RefreshWeaponUI()

Request a re-push of the current weapon's ammo readout + magazine display (no pool resubscribe). Call after inventory contents change (close, interaction pickup) so the reserve count and the Tarkov-style magazine list — which walks inventorySystem.allGrids — stay in sync. The push is deferred to end-of-frame so it sees the completed inventory state.
