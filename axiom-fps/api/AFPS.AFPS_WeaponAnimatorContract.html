Class AFPS_WeaponAnimatorContract

Single source of truth for the weapon animator template's state names, parameter names, and their pre-hashed IDs. Users extending the template keep the runtime working by keeping these names — nothing else in the system contains an animator string literal, so editing this file and regenerating the template is the only change needed to alter the contract.

Every hash is a static readonly computed from a const string: a pure computation with no mutable static state, so it survives Enter Play Mode with domain reload disabled.
