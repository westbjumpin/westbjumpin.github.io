Enum DashVelocityReset

Which components of the player's velocity zeroVelocityBeforeDash clears, so a dash can wipe the slate without also throwing away a jump arc.

Namespace: AFPS
Assembly: AxiomFPS.Runtime.dll
Syntax
public enum DashVelocityReset

Fields

Name Description
All

Clear the whole velocity vector. The dash is the only momentum the player leaves with.
Horizontal

Clear the X/Z velocity and leave the vertical component untouched, so a dash mid-jump keeps its arc.
Vertical

Clear the vertical velocity and leave the horizontal run untouched — kills a fall before an upward dash without stopping the player dead.
