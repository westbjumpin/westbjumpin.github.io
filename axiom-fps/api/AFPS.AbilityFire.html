Class AbilityFire

Bridges the ability system into the weapon system: a fire script that activates an AbilityBase instead of emitting a shot, so any ability can be the way a weapon fires. Drop it into a weapon's primary or secondary fire scripts and the weapon's existing pipeline — fire type, fire rate, burst, recoil profile, sprint interrupt, equip/drop — drives the ability.

Trigger timing belongs entirely to the weapon. The ability's own abilityTriggerType and triggerRate are ignored here — those drive the AFPS_AbilitySystem slot path, and honouring both would put two invisible cooldowns on one trigger. The ability keeps ownership of validity through CanActivate(), which gates the recoil kick.

Press/release map straight across, because Fire(released) and ActivateAbility(pressed) are inverses of each other: pair a held ability such as GrapplingHook with the OnPressAndRelease fire type and set AFPS.AbilityFire.holdToUse, and press-to-grapple / release-to-let-go works with no ability-specific code.
