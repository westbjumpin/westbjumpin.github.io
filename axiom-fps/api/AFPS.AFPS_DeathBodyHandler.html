Class AFPS_DeathBodyHandler

Optional companion to AFPS_DeathController that decides what the camera is looking at during a death. A freezecam or orbit shot pointed at a hidden first-person capsule looks broken — this is what gives those modes a subject.

Add it to the player only when the death screen actually leaves first person; the controller works fine without it. Whatever this produces is written back into body, which is the transform every camera mode frames.

SpawnedCorpse

The corpse instantiated for the current death, or null when none is standing — the mode is not SpawnCorpsePrefab, or the body has been restored on respawn.

Read it to hang something off the body: a map marker, a decal, or the dropped inventory when AFPS_InventoryDeathHandler is set to attach its container to the corpse. It is assigned during HandleDeath(DeathContext), so anything reacting to OnDied runs too early to see it — wait a frame, as that handler does.
