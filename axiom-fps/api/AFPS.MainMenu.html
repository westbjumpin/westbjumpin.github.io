Namespace AFPS.MainMenu

Classes

ControlsTabView

Controls tab inside OptionsPanel. Owns the keybindings list UI, scheme switcher, reset controls, and the interactive rebind flow. State lives in KeybindingsService; this view is presentation only.

GameSettings

KeybindingOverrideRecord

Persisted binding override: action name, scheme group string, slot index, and override path.

KeybindingOverridesData

JSON root for persisted binding overrides; deserialized by KeybindingsService.LoadFromJson.

KeybindingsService

Static rebinding facade over the Player action map. Owns the dual-mapping (Primary/Secondary) schema and the persistence format. Does NOT own the InputActionAsset itself — AFPS_InputManager owns it. The Player map is the only rebindable scope; Inventory/UI maps are excluded by design (menu plumbing).

LevelDatabase

LevelEntry

LevelLoader

Stateless helper that async-loads a LevelEntry's scene via SceneManager.LoadSceneAsync.

LevelSelectView

Level-select view: procedurally builds a card grid from LevelDatabase; card clicks raise MenuEvents.RaiseLevel.

MainMenuController

MainView

Main-menu root view: wires Play, Options, and Exit buttons to MenuEvents; disposes subscriptions on Dispose.

MenuEvents

Static event bus for main-menu navigation: views raise events, MainMenuController/PauseMenuController subscribe and drive the MenuStateMachine.

MenuStateMachine

Push-down automaton for menu navigation: Go pushes history, Back pops to prior state; Enter/Exit callbacks drive visibility transitions.

OptionsView

Tabbed options view (Video/Audio/Gameplay/Controls): binds UI Toolkit sliders/dropdowns to GameSettings, applies via SettingsService, and owns a ControlsTabView child.

PauseMenuController

In-game pause menu. UIDocument toggled via AFPS_UIManager.pauseMenu SetActive. Reuses OptionsPanel.uxml for parity with the main menu.

SceneReference

Serializable scene pointer: stores SceneAsset in-editor, bakes path/name strings for runtime (build-safe, no SceneAsset dependency at runtime).

SettingsService

ViewState

IMenuState backed by a VisualElement: toggles view--hidden/view--active USS classes on Enter/Exit and defers focus to the first selectable button.

Structs

RebindableEntry

Display metadata for one rebindable action: actionName (Input System key), UI label, and category group header.

Interfaces

IMenuState

Menu screen contract: named view that can be entered and exited by MenuStateMachine.

InventoryNavMode

Gamepad navigation mode for the inventory UI: grid-snap jumps cell-to-cell, VirtualPointer drives a synthetic mouse cursor.

QualityPreset

Graphics quality tier mapped to QualitySettings.SetQualityLevel index.
