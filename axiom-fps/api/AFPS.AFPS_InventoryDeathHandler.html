Class AFPS_InventoryDeathHandler

Decides what happens to the player's inventory when they die: keep it, drop it into a lootable container at the death position, or destroy it.

Hooks OnDied, which fires before either respawn path runs, so the death position is still the player's real one. Nothing else in the death system touches the inventory, so this component is the whole feature — remove it and deaths keep everything.

Dropped items keep their identity: stack sizes, rotation, nested storage, and the world objects they were picked up from all survive into the container, so looting your own grave returns exactly what you lost.

Drop To Container can put the loot in its own container on the ground, or inside the corpse the death sequence spawns so the body itself is the stash — see DeathContainerPlacement. This is the player's body-loot component; AFPS_CorpseContainer is the NPC equivalent and refuses to run alongside it.

Setup: put it on the player next to AFPS_InventorySystem, leave the references empty to auto-resolve, and pick a policy. Drop To Container additionally needs a prefab carrying an AFPS_ContainerInventory.
