useArms

Whether the shared movement-arms rig (driven by AFPS_ArmsController) is shown while this weapon is equipped. Set true only for weapons that have no arms of their own — the shared rig then serves as the hands. Set false for weapons that carry their own arms (an AFPS_WeaponAnimator rig, or arm meshes baked into the model); the shared arms then stay hidden except while climbing, ledge-hanging, or mantling, where they are forced visible and the weapon's own arms are hidden for that window — leaving this on for such a weapon draws the shared arms on top of its own, showing four arms.

CancelReloads()

Cancels any in-progress reload (and pending reload-hold) on every ammo pool on this weapon. Called whenever the weapon stops being the active weapon — switched away, holstered, dropped, or unequipped — so a reload can't keep running in the background (the weapon GameObject stays active on a switch, only its model is hidden) and complete on a weapon the player isn't holding.

DropSwapTargetOccupant(AFPS_WeaponSystem)

Hybrid swap path (inventory enabled + alwaysUseWeaponSwap): drops the weapon occupying this weapon's resolved target slot so the subsequent normal grid pickup can equip this weapon there (and keep it represented in the inventory). No-op when the slot is already free, or when this weapon doesn't equip on pickup — in that case it would just stash in the grid, so dropping the occupant would throw away the player's weapon for nothing.
