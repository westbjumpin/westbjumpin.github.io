Class StatusEffect

Runtime instance of a status effect: tracks build-up accumulation, remaining apply time, reapply timer, and HP/overheal deltas per tick. Instantiated from AFPS_StatusEffect via GiveNewStatusEffect(AFPS_StatusEffect).
