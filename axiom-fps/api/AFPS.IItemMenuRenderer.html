Interface IItemMenuRenderer

Renderer-agnostic right-click item menu. Implemented by UGUI (AFPS_ItemMenuController) and UI Toolkit (AFPS_ItemMenuUIToolkit). Inventory dispatches via a single activeItemMenu reference — same pattern as IHUDLayer.

TryActivateAt(Vector2)

Activate the button under screenPosition if one exists. Used by the controller path: virtual cursor never fires native PointerClick on either renderer, so the inventory has to dispatch the synthetic click via this hook. Return true if a button was hit (caller leaves the menu alone — handlers Hide() themselves), false if the click was outside any button (caller dismisses the menu).
