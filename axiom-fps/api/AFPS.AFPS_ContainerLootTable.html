Class AFPS_ContainerLootTable

Weighted loot table for AFPS_ContainerInventory. Rolls a list of StoredItemDescriptor entries — the same serialisable shape the rest of the inventory uses for nested storage — so the result can sit dormant on a closed container and be materialised into real item objects the first time it is opened.

Two passes run per roll: guaranteed entries always attempt (gated only by their own chance), then weighted entries fill the remaining roll count, picked proportionally to weight.
