Class AFPS_VFXStatusBehaviour

Status behaviour that shows an in-world VFX on the target while the effect is active — fire on a burning enemy, frost on a chilled one. It spawns a prefab when the effect starts and destroys it when the effect ends.

Two simple pieces make it up: this behaviour (drop it on the status effect, set the prefab and which anchor to attach to) and AFPS_StatusVFXAnchor markers you place on bones, each authoring WHERE the VFX sits plus its world rotation and scale there. If an enemy has no matching anchor, the VFX attaches to the target root — so it works on any target, authored or not. For a per-enemy look (a different prefab on a specific enemy) add an AFPS_StatusVFXBinder to that enemy; otherwise this default is used everywhere.
