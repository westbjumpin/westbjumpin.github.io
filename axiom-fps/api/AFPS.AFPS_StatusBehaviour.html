Class AFPS_StatusBehaviour

Base ScriptableObject for a non-HP side effect of a status (slow, freeze, VFX, …). An AFPS_StatusEffect lists any number of these; AFPS_Health drives their lifecycle: OnApplied(AFPS_StatusContext) once when the effect is added, OnTick(AFPS_StatusContext) on every reapply tick, and OnExpired(AFPS_StatusContext) once when it ends (by timeout, chain, or being cleared on respawn — so anything applied in OnApplied(AFPS_StatusContext) is always undone).

Behaviours are shared, stateless config (one asset drives many targets); keep per-target state on the target, keyed by instance. See AFPS_MoveSpeedStatusBehaviour for a worked example.
