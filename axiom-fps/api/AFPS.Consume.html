Class Consume

Spends one unit of the item and applies its effects to the player: healing, overheal, damage, and any number of status effects. Covers medkits, bandages, food, stimulants, drugs with a downside, and poison — all from the same button prefab, configured per item menu.

The item is only spent when something actually happened, so a full-health player clicking a medkit doesn't waste it (turn off requireEffect if you'd rather they could).

Effects are applied through AFPS_Health's normal paths, so damage numbers, the health HUD, resistances and kill attribution all behave exactly as they do for world damage.
