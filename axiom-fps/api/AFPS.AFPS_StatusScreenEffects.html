Class AFPS_StatusScreenEffects

Player-side receiver that renders full-screen status overlays (frost, fire, poison haze) and, optionally, fires the camera's vignette. It is a singleton — the local player owns the one instance — so status behaviours can reach it from anywhere via Instance without a scene reference.

Setup (one receiver per scene, on the local player's HUD): add this component to a Screen Space - Overlay Canvas — or to any child of one — or leave it anywhere and assign a Canvas to AFPS.AFPS_StatusScreenEffects.overlayCanvas. AFPS_ScreenEffectStatusBehaviour drives it. Overlays are keyed by the applying effect instance, so each active effect gets its own layer and cleans up independently.
