Class AFPS_WeaponAnimator

Drives a weapon's Mecanim Animator from the gameplay events the existing weapon systems already raise (fire emitted, reload started/ended, equip/de-equip started), so authored clips play on the rig BELOW the weapon root while bob, sway, tilt, recoil, bump and ADS keep composing the root itself in AFPS_WeaponSystem.

Everything here is optional and additive. With no Animator, no override controller, or an empty clip slot, the matching procedural behaviour (LeanTween equip tween, reload tilt stance) runs exactly as it did before this component existed — a weapon that never gets one is untouched.

Gameplay stays authoritative: clips adapt their playback SPEED to the fire rate and ReloadDuration, never the other way round. Animation events are cosmetic only (see AFPS_WeaponAnimationEventReceiver).

Lives on the weapon ROOT beside AFPS_WeaponObject; the Animator itself must live on or under the weaponModel child, because the root's localPosition/localRotation is rewritten every frame by AFPS_WeaponSystem and an Animator there would fight it.

HolsterDuration

Seconds the de-equip should wait when a Holster clip is present — clip length ÷ AFPS.AFPS_WeaponAnimator.holsterSpeedMultiplier, i.e. exactly as long as the clip takes to play. EquipEndingAnimation() waits this instead of its tween duration, so the weapon is never hidden mid-animation. 0 when no Holster clip is slotted.

HandleEquipStarted()

Equip: the weapon model has just been re-activated, which rebinds the Animator and clears its parameters — so playback is re-established from zero here rather than assuming anything about the previous state. That is also what makes an interrupted switch harmless. Override to add your own draw behaviour; call base to keep the shipped one.

HandleFireEmitted(FireWeaponBase, bool)

Fire: one call per ACTUAL emission (per burst bullet, at the deferred moment for delayed fire scripts, never on a dry fire). Restarts from normalised time 0 every shot so a fire rate shorter than the clip retriggers cleanly instead of letting the clip run on. Never gated, never queued — the shot already happened; the animation must not pretend otherwise.
