Class AFPS_WeaponAmmo

One ammo pool per weapon. In Magazine mode the loaded mag is an AFPS_ItemObject inside the weapon's storedItems; bullets are stacked AFPS_ItemObjects inside that mag's storedItems (LIFO fire order, mixed ammo allowed).
