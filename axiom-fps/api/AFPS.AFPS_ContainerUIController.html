Class AFPS_ContainerUIController

Player-side owner of the secondary ("container") inventory panel. One pooled AFPS_InventoryGrid is re-sized and re-pointed for whichever AFPS_ContainerInventory the player has open, so a 3x2 ammo box and a 10x6 corpse share the same grid, binding and UI element.

It binds and unbinds containers (one at a time), marks the grid external so the rest of the inventory treats its contents as not-yet-owned loot, drives the UXML panel (title, live weight, Close and Take All), and closes the container when the inventory closes, the player walks away, or the player dies.

Place it on the same GameObject as AFPS_InventorySystem (or anywhere in the player hierarchy) and point it at the secondary grid. The UXML fields are optional: with no UIDocument assigned it still binds containers and simply shows/hides the grid GameObject, which is what a UGUI-based setup wants.
