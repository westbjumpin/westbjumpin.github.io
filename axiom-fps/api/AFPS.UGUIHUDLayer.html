Class UGUIHUDLayer

UGUI IHUDLayer. Owns the legacy Canvas-based HUD widgets and renders the full IHUDLayer surface. Mirrors UIToolkitHUDLayer's patterns: epsilon-gated change detection, null-guards, pool reuse. TriggerImpulse is a no-op — UGUI impulse is delivered by AFPS_UIImpulse components via BroadcastMessage.
