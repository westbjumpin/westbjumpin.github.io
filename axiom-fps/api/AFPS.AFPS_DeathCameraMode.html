Class AFPS_DeathCameraMode

Base class for everything the camera can do while the player is dead. Subclass, override Sample(DeathContext, float), and the asset gets a new death camera with no changes to the death controller — the same extension model as AbilityBase.

Subclasses only describe where the camera wants to be; the blend from the pose the player died holding into that target is handled here so every mode gets easing, dolly-in, and FOV blending for free.

Runtime state: modes are shared assets, so any per-death state a subclass caches must be reset in Begin(DeathContext). The shipped modes are pure functions of elapsed time and the context.

ResolveActiveMode(DeathContext)

Which mode should actually run for this particular death. Called once by AFPS_DeathController before Begin(DeathContext), and the returned mode is the one begun, evaluated, and ended — so a mode can hand off entirely rather than wrapping another and blending twice. Default is "myself"; AFPS_KillerDeathCamera overrides it to fall back when there is no killer to frame.

Sample(DeathContext, float)

The pose this mode wants at elapsed seconds into the sequence, ignoring the blend-in — return the settled pose and the base class handles easing into it. Time is unscaled, so modes keep moving under death-screen time dilation.
