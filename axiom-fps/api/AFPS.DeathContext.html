Class DeathContext

Everything the death flow knows about one death, built once by AFPS_DeathController and handed to every subsystem that participates: camera modes, the death screen, respawn strategies, and user code listening on the controller's events.

This is a class rather than a struct on purpose — camera modes read it every LateUpdate, and the body handler writes body back into it after spawning a corpse.
