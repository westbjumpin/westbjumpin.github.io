Class AFPS_SpreadProfile

Authoring asset for per-weapon bullet spread. Defines a spread cone (maxSpreadAngle) plus how individual pellets are placed inside it: Random (uniform / gaussian / ring distribution) or Fixed (hand-authored deterministic pellet layout). Fire scripts call ApplySpread() per pellet; there is no runtime state — spread is computed fresh each shot.
