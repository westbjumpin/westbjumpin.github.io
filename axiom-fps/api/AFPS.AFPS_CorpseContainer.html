Class AFPS_CorpseContainer

Turns a dead entity into a lootable body. Watches an AFPS_Health and, the moment it dies, fills the AFPS_ContainerInventory on this GameObject with the entity's gear — a death loot table, an authored carried-items list, and optionally its equipped weapons — then enables the container so the player can interact with it.

While alive the container component is disabled, which is the interaction system's off-switch: no interaction box, no prompt, no Interact() call. A living enemy therefore shows no loot affordance without any extra wiring.

For NPCs only. On the player it refuses to run and points you at AFPS_InventoryDeathHandler, which answers the same question without riding along through respawn as a lootable body attached to the living player.

Setup: put this and AFPS_ContainerInventory on the entity (or on a child owning the corpse collider), leave the references empty to auto-resolve, and give the container a verb like "Loot". The collider the player looks at must be on the same GameObject as the container — the interaction system reads the collider it hits, and does not walk up to parents.
