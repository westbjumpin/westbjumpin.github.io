Interface IDeathSequence

Implemented by whatever owns the window between dying and respawning. Die() looks for one on its own GameObject and, if HandleDeath(AFPS_Health) accepts, stops there — leaving isDead latched and handing the entity over.

The contract is deliberately one method: the presence of the component is what switches the asset from the legacy instant-checkpoint respawn to a full death sequence, so projects that never add one behave exactly as they did before. AFPS_DeathController is the shipped implementation.

HandleDeath(AFPS_Health)

Take ownership of this death. Return true to keep the entity dead and run the sequence — the implementer is then responsible for eventually clearing the death latch (see ClearDeathState()). Return false to decline, which falls back to AFPS_Health's built-in behaviour.
