Class AFPS_MoveSpeedStatusBehaviour

Status behaviour that scales the target's movement speed while active — the "Cold slows you" effect. Registers a multiplier on the target's AFPS_Movement in OnApplied(AFPS_StatusContext) and removes it in OnExpired(AFPS_StatusContext), keyed by the effect instance so multiple slows stack and each cleans up independently. No-ops on targets without an AFPS_Movement (e.g. AI actors).
