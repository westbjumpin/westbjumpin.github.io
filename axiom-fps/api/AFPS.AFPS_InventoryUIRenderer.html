Class AFPS_InventoryUIRenderer

Top-level UI Toolkit renderer. Hides the original UGUI inventory canvas and draws a "held item" mirror VisualElement that follows the mouse, mirroring inventorySystem.currentItem each frame (sprite, size, rotation).

Pair with one AFPS_InventoryGridUIBinding per AFPS_InventoryGrid. All coordinate conversions go through the binding's PanelPerScreen helper so the renderer is robust to PanelSettings scale-mode changes.
