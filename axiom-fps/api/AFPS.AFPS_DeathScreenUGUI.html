Class AFPS_DeathScreenUGUI

UGUI death screen, for projects still on the Canvas-based HUD. Functionally identical to AFPS_DeathScreenUIToolkit — same contract, same settings, same behaviour — so the two can be swapped on the controller without touching anything else.

Every reference is optional: wire up only the pieces the screen actually shows.
