Getting Started

Requirements

Important

URP and TextMeshPro must be set up in your project before you import Axiom FPS. They are not installed for you. If either is missing you will see compile errors, pink materials, or missing text. See Prepare your project below.

  • Unity 6000.3 (Unity 6) or newer.
  • A project using the Universal Render Pipeline (URP) (com.unity.render-pipelines.universal). Axiom FPS ships URP materials, shaders, and render settings; it is not compatible with the Built-in pipeline or HDRP (materials will appear pink).
  • TextMeshPro, with the TMP Essential Resources imported into Assets/TextMesh Pro/. On Unity 6, TextMeshPro ships inside the UI package (com.unity.ugui), so the package itself is already there — but the essential resources are a separate, manual import.
  • Input System (com.unity.inputsystem), with the project's Active Input Handling set to Input System Package (New) or Both.
  • Visual Effect Graph (com.unity.visualeffectgraph) for the included VFX.

Prepare your project

Do this in the project you are importing into, before importing the package:

  1. Use a URP project. Either create a new project from the Universal 3D template, or add URP to an existing project:
    • Window ▸ Package Manager ▸ Unity Registry, install Universal RP.
    • Create a pipeline asset (Assets ▸ Create ▸ Rendering ▸ URP Asset (with Universal Renderer)) and assign it under Project Settings ▸ Graphics ▸ Default Render Pipeline, and in each quality level under Project Settings ▸ Quality.
  2. Import TMP Essential Resources. Window ▸ TextMeshPro ▸ Import TMP Essential Resources. This creates Assets/TextMesh Pro/ — without it, all HUD and menu text renders as missing/pink.
  3. Install the Input System (Package Manager ▸ Unity Registry ▸ Input System) if it isn't already, and set Project Settings ▸ Player ▸ Active Input Handling to Input System Package (New) or Both. Unity will ask to restart the editor.
  4. Install Visual Effect Graph (Package Manager ▸ Unity Registry ▸ Visual Effect Graph).

Installation

  1. Open or create a URP project in Unity 6 and complete Prepare your project above.
  2. Import the Axiom FPS package.
  3. If prompted, accept any package-dependency installs and let Unity finish compiling.
  4. Open the onboarding window any time from Tools ▸ AFPS ▸ Get Started. Its Requirements section checks your project and flags anything still missing.

Troubleshooting setup

Symptom Cause Fix
Materials are pink/magenta URP is not installed, or no URP asset is assigned as the active render pipeline Install Universal RP and assign a URP asset in Project Settings ▸ Graphics and Quality
Text is missing, or shows as pink boxes TMP Essential Resources not imported Window ▸ TextMeshPro ▸ Import TMP Essential Resources
Compile errors mentioning UnityEngine.Rendering.Universal URP package missing Install Universal RP from the Package Manager
Compile errors mentioning TMPro TextMeshPro missing Install the UI package (com.unity.ugui) from the Package Manager
Compile errors mentioning UnityEngine.InputSystem Input System package missing Install Input System from the Package Manager
Input does nothing in Play mode Active Input Handling set to the old system Project Settings ▸ Player ▸ Active Input Handling ▸ Input System Package (New) or Both

Run the demo

  1. Open Assets/Axiom FPS/Scenes/Firing Range.unity.
  2. Press Play.
  3. Move with WASD, look with the mouse, and use the on-screen HUD to learn the rest of the controls. Try sprinting, sliding, mantling, the abilities, and the example weapons.

Tuning the feel

Almost everything is driven by ScriptableObject presets in Assets/Axiom FPS/Presets/. To adjust a system:

  1. Browse to the relevant preset (e.g. Presets/Movement/Sprint, or Presets/Weapon System/Weapons/Assault Rifle/Recoil Settings).
  2. Edit the values in the Inspector.
  3. Enter Play mode to feel the change — no code changes required.

Calling Axiom FPS from your own code

All runtime types live in the AxiomFPS.Runtime assembly under the AFPS namespace. To reference them from your own scripts, add AxiomFPS.Runtime to the Assembly Definition References of your assembly definition. Browse the API Reference for the full list of public types.
