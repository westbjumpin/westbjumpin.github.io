Class AFPS_Health

Core HP component: manages base HP and overheal pools, per-type damage resistances, status effect lifecycle, death/respawn flow via AFPS_CheckpointManager, and drives AFPS_UIManager health HUD.

OnDamageDealt

Static, fires once per resolved damage/heal that flows through ApplyDamage(DamageInfo), carrying the post-resistance magnitude and hit geometry. UI systems (e.g. floating damage numbers) subscribe here so AFPS_Health stays UI-agnostic. Distinct from OnDamaged, which carries the pre-resistance DamageInfo.
