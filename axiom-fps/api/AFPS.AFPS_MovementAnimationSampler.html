Class AFPS_MovementAnimationSampler

Builds an AFPS_MovementAnimationSnapshot from an AFPS_Movement.

This exists so the swim and locomotion rules live in exactly one place. They were duplicated the moment a second animation system needed them, and duplicated rules drift: the arms and the weapon disagreeing about whether the player is swimming is a bug nobody would think to look for.

Pure and allocation-free — safe to call every frame, and safe under Enter Play Mode with domain reload disabled (no static state of any kind).
