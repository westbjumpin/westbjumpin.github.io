Struct AFPS_KillInfo

A resolved "who killed whom" record, built by AFPS_Health whenever ANY entity dies — player, AI, or a destructible prop — and delivered through the health's OnKilled event and the static OnAnyKilled event. Both are empty hooks by default: subscribe to drive a killfeed, scoring, on-death loot, AI aggro, achievements, and so on, without touching the health system itself.

It reads the victim's latched LastDamage, so status-effect deaths attribute correctly (a death from your rocket's Burn credits you), matching the floating-number and death-screen attribution.

selfInflicted

True when the killing blow's instigator resolves back to the victim — their own explosive, their own fire, an explosive barrel they shot. An unattributed death with no instigator (a fall, drowning, an environmental effect) is NOT self-inflicted, since there is nothing to credit; hasKiller is then still true but the killer fields stay empty.
