CanAcceptExternalItem(AFPS_ItemObject, AFPS_InventoryGrid, AFPS_ItemObject)

True when destination may take item without breaking the carry-weight cap. Only external-container origins are weighed: an item already inside the player's own storage costs nothing extra to move around, and gating it would make an over-encumbered player unable to put their own item back down. Pass the item a swap is displacing as displaced so its weight, which the same operation frees, isn't double-counted against the incoming one.

RemoveItem(AFPS_ItemObject)

Destroys the item GO and clears its grid cell references. Also despawns the world object the item was picked up from: a stashed pickup is parked disabled under this inventory and nothing else references it, so leaving it behind accumulates dead GameObjects for the rest of the session.

Only stashed pickups are despawned. An interactable that is still active is either lying in the world or equipped in the player's hands, and owns its own lifetime — an equipped weapon leaves through Drop(), not through here.

TryQuickEquip(AFPS_ItemObject)

Modifier-click with no container open. Mirrors the container gesture minus the container:

  1. Item in an equipment slot → back into the player's storage. Same rule as with a container open, so stripping gear reads identically whether or not a chest happens to be in front of them.
  2. Otherwise → an equipment slot that claims its category, then a grid that explicitly claims it (an ammo pouch, a weapon rack). Wildcard grids are never targeted, so this can't shuffle an item between general stashes for no reason.

An item with no home simply stays put, silently — that is what the gesture should mean. The one refusal worth reporting is a failed unequip, which means the player's storage is full.

TryQuickTransfer(AFPS_ItemObject)

Modifier-click with a container open. Resolves to the move the player almost certainly meant, in priority order:

  1. Item in the container → into the player's storage.
  2. Item in an equipment slot → back into the player's storage, never straight into the container. Stripping gear is a separate decision from stashing it, and one click shouldn't do both.
  3. Item in the player's storage with a free slot that claims its category → equip it.
  4. Anything else → into the container.

Flashes the refusal reason on the HUD, or under the container's grid, when the move is refused.
