Changelog

Changes to Axiom FPS, newest first.

Latest release

Death System

  • New death and respawn flow with death cameras (killer cam, orbit, follow body, freeze, keep first-person), respawn strategies (checkpoint, spawn point, reload scene, custom event), and death screens for both uGUI and UI Toolkit. All preset-driven. See Death and Respawn.

Damage Types

  • Damage kinds are now ScriptableObject assets instead of a fixed enum, each carrying a display name, UI colour, death-screen wording, and status effects to apply on hit. Ten presets included (Ballistic, Fire, Explosive, Poison, and more). See Damage Types and Status Effects.

Status Effects

  • Rebuilt on modular status behaviours covering damage over time, move speed, knockback, control lock, screen effects, and VFX. Over twenty presets included (Burn, Bleed, Poison, Frozen, Stun, Flashbang, Haste, Regeneration, and more).
  • Added full-screen status overlays (frost, fire, blind/flashbang) and world-space status VFX that follow the affected character.

Health

  • Every death now raises a kill record naming the victim, killer, weapon, and damage type — ready for killfeeds, scoring, and on-death loot. Status-effect kills credit the original attacker.

Movement

  • Added a reference-counted control lock over movement, look, and firing, so overlapping stuns and knockbacks release cleanly instead of fighting each other.

Weapon Animations

  • New weapon animator drives Mecanim clips from the events weapons already raise (fire, reload, equip). Clip speed follows fire rate and reload duration, and weapons without an Animator behave exactly as before.
  • Added a setup wizard, an animator template generator, placeholder clips for every state, and a custom inspector for wiring a weapon up. See Weapon Animation.

Movement Arms

  • The shared first-person arm rig — used for climbing, ledge hangs, mantles, slides, crouching, running, and swimming — can now play animation clips through the same slot-and-contract system as the new weapon animator, with a template generator and one-button setup. Projects using the old arms controller keep working unchanged in a legacy mode. See Movement Arms Animation.

ADS

  • Added an editor preview that renders the aimed pose live in the Game view, plus a validation window that flags rig setup problems before you hit Play.
  • The aimed pose is now evaluated by shared code used at runtime and in the editor, so what you preview cannot drift from what the player sees. See Tuning ADS.

Abilities

  • Dash overhauled — every tuning value moved into swappable presets, with selectable dash directions (input, aim, upward) and hover suppression so launches are not flattened. Realistic, Movement Shooter, and Old School presets included.
  • Grappling Hook overhauled — attach rules, reel and momentum, pendulum tension, swing control, movable anchors, and auto-detach are now all preset-driven. Swap the preset to swap the whole feel. Realistic, Movement Shooter, and Old School presets included.
  • Weapons can now fire an ability as their fire action.

Inventory

  • Added container inventories with weighted loot tables, rolled on spawn, on first open, or on every open while empty (for restocking stashes).
  • Enemies and the player can now drop lootable bodies, carrying their loot table, carried items, and optionally their equipped weapons.
  • Added a configurable policy for what happens to the player's inventory on death — keep everything, drop it into a lootable container at the death position, or destroy it.
  • Added Equip, Transfer, and Unload item menu actions, plus item transfer between two open containers.
  • Added a per-item Sprite Tint — a colour multiplied over the item's inventory icon in every view (grid, drag, equipment slots, and the uGUI example), so a shared sprite can be recoloured per item without new art. See World Containers and Looting.

Interaction

  • Weapon pickups support hold-to-swap when the target slot is full, with a verb prompt and hold-progress radial on the HUD.
  • HUD prompts now render through a shared layer with both uGUI and UI Toolkit implementations.

Props

  • Added a spawn-on-death component so explosive props credit their kills to whoever set them off, including chain reactions and self-inflicted blasts. Wired into the Firing Range explosive barrels.

Content

  • Added the VSK rifle as a fully configured example weapon, with its own inventory item, a dedicated magazine, and a tinted variant of the rifle round for its ammo.
  • Each weapon's tilt and descriptor presets now sit in that weapon's own folder alongside its stats, recoil, and fire settings, instead of separate shared folders.

Fixes and improvements

  • Fixed: weapon sway, bob, bump, and tilt were frame-rate dependent, so feel tuned on one machine was wrong on another. They are now frame-rate independent, and existing tuning values still read the same.
  • Fixed: many various bugs relating to ADS, movement, and firing.
  • Documented the URP and TextMeshPro setup steps that must be done before importing.
  • Added a Requirements section to the onboarding window that checks your project and offers one-click fixes.
  • Added a setup troubleshooting guide to the README and online docs.
  • Completed the scripting API reference so every public type is documented, with engine and inspector-only members filtered out to keep it focused on the API you call.
