ResolveSpringCoefficients(int, out float, out float, out float)

Resolves the spring coefficients for one axis. In Raw mode returns the fields verbatim; in Tuned mode derives k/c/m from settleTime + dampingRatio so designers tune behavior, not physics. m = 1 (only ratios matter; constant mass keeps amplitudes consistent) ω₀ = 4 / settleTime (2% settling time of a critically-damped second-order system) k = m * ω₀² c = 2 * ζ * √(k * m)
