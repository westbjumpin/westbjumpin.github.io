Introduction

Axiom FPS is a modular first-person movement and combat framework for Unity 6 built on the Universal Render Pipeline. It ships as a ready-to-play project with demo scenes, example weapons and props, and a set of systems that you can use together or pick from individually.

Design philosophy

  • Data-driven. Nearly every system is configured through ScriptableObject presets under Assets/Axiom FPS/Presets/. You tune movement feel, recoil patterns, camera effects, and balance from the Inspector — no recompiling.
  • Modular. Systems communicate through clear components and events, so you can drop in just the movement controller, or use the full stack.
  • Self-contained. All runtime code lives in the AxiomFPS.Runtime assembly (root namespace AFPS), and bundled third-party libraries are isolated in their own assemblies, so nothing collides with your project code.

The systems

System What it does
Movement Grounded/air movement, sprint, crouch + slide, mantle, vault, climb, ladders, wall interaction, stamina, slope handling, and explosion knockback.
Camera Headbob, FOV effects, hit-bob, and movement-driven camera motion.
Weapon Hitscan and projectile weapons, recoil and spread profiles, weapon tilt/sway, and ammo handling.
Ability Modular abilities (e.g. Dash, Grapple) via an ability holder.
Health Damage, healing, damage types/resistances, and related events.
Inventory Grid inventory with UI Toolkit and uGUI example renderers and item menus.
Interaction A generic interactable framework for pickups, doors, draggables, and triggers.
Agent + Teams Team/affiliation data for the player, enemies, and props.
Input Pre-configured Input Actions (AFPS_PlayerActions) built on Unity's Input System.
UI UI Toolkit HUD plus a full main menu and pause menu.

Demo scenes

Found under Assets/Axiom FPS/Scenes/:

  • Firing Range — the main playground showcasing movement, weapons, and abilities.
  • Main Menu — the UI Toolkit main menu, options, and level select.
  • UGUI Inventory Example — the inventory implemented with uGUI, to show an alternative to the UI Toolkit HUD used in the main demo.
