Class AFPS_Health

Core HP component: manages base HP and overheal pools, per-type damage resistances, status effect lifecycle, death/respawn flow via AFPS_CheckpointManager, and drives AFPS_UIManager health HUD.

Die()

GiveNewStatusEffect(AFPS_StatusEffect, GameObject)

Instantiates a runtime StatusEffect from statusEffect and adds it to currentStatusEffects, enforcing the source SO's stack cap. The target's matching StatusEffectResistance can block it outright or scale its duration, per-tick HP impact, and behaviour strength. Pass instigator (the shooter/exploder) so the effect's damage-over-time ticks credit them for damage numbers and kills; leave null for environmental/unattributed effects. No-ops on dead targets or null input.

RefreshHealthUI()

Clamps the HP/overheal pools back into their valid ranges and pushes the current values to the health HUD. Call after any external HP restore (checkpoint reset, respawn strategy) so the display reflects the restored value — otherwise the sub-zero HP an overkill blow left behind (the HUD was last updated mid-lethal-hit, and AFPS.AFPS_Health.Update() doesn't run while dead to clamp it) stays on screen as e.g. "-60" after respawn.

RemoveStatusEffects(AFPS_StatusEffect)

Removes every active effect that came from source — the antidote / bandage case, where one item cures one named condition rather than everything at once.

Routes through the same removal path as natural expiry, so each behaviour's OnExpired(AFPS_StatusContext) runs (a Cold slow is lifted, not left stuck) and OnStatusExpired fires for each instance.
