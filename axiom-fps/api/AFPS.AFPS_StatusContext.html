Struct AFPS_StatusContext

Snapshot of who a status behaviour is acting on, passed to every lifecycle hook on AFPS_StatusBehaviour. Carries the target's AFPS_Health and the specific runtime StatusEffect instance — behaviours use instance as a per-effect key so each stack registers and cleans up its own state (e.g. one slow multiplier per Cold stack).

Strength

Behaviour-strength factor in [0,1] from the target's status resistance: 1 = full strength, 0 = neutralised. Scale your effect by this — e.g. lerp a slow toward no-slow, dim a screen overlay, shrink a knockback impulse, or skip a control lock at 0. HP damage and duration are handled by the health system before OnApplied(AFPS_StatusContext) runs, so behaviours only apply this to their non-HP side. 1 when the effect has no per-instance strength.
