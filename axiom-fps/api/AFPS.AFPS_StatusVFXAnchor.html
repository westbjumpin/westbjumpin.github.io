Class AFPS_StatusVFXAnchor

Marks a point on a character where status VFX can attach, and authors how the VFX sits there. Place these on bones or empties (chest, head, hands) and give each an anchorId; an AFPS_VFXStatusBehaviour whose anchor id matches spawns its VFX at this transform, applying the rotationEuler and scale below as WORLD values (not multiplied by this bone's own rotation/scale), so the VFX reads the same wherever the bone happens to be pointed or scaled. Several anchors may share an id to place the same effect at multiple points (e.g. fire on both hands), each with its own rotation and scale. Optional — an enemy with no anchors just gets the VFX at its root.
