Axiom FPS

A complete, data-driven first-person movement & combat framework for Unity 6 (URP).

Axiom FPS gives you a polished first-person controller and the surrounding systems you need to build a shooter — advanced movement, weapons with recoil and spread, abilities, health, inventory, interaction, UI, and more — all tunable through ScriptableObject presets without touching code.

Get Started  •  API Reference

Highlights

  • Movement System — grounded/air control, sprint, crouch + slide, mantle, vault, climb, ladders, wall interaction, stamina, slopes, and explosion knockback.
  • Weapon System — hitscan & projectile weapons with configurable recoil, spread, and weapon tilt; example weapons included (AK-47, RPG-7, Revolver, Sniper, Sawed-Off Shotgun).
  • Camera System — headbob, FOV effects, hit-bob, and movement-driven camera motion.
  • Ability System — modular abilities such as Dash and Grapple.
  • Health, Inventory, Interaction, Teams — damage/healing, UI Toolkit & uGUI inventories, an interactable framework, and team/affiliation data.
  • UI & Input — UI Toolkit HUD, full main/pause menu, and pre-configured Input Actions.

Most behaviour is exposed through ScriptableObject presets, so you can tune feel and balance entirely from the Inspector.

Requirements

  • Unity 6000.3 (Unity 6) or newer
  • Universal Render Pipeline (URP) — the asset ships URP materials, shaders, and render settings. It is not compatible with the Built-in pipeline or HDRP.
