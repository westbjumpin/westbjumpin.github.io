Class CompassRegistry

Static registry of marker sources. Sources Register in OnEnable / Unregister in OnDisable; AFPS_Compass walks the set on its poll tick. Static because the framework assumes one compass and one player per scene — avoids per-frame FindObjectsOfType and avoids a source→compass singleton dependency.
