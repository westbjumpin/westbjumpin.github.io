OnDisplayRefreshed

Fired at the end of RefreshSprite() — the shared call-in for all count-driven display on this item. External display that mirrors the sprite-by-count system (e.g. AFPS_AmmoStateToggle on the weapon, reading this item's storedItems) subscribes here so it updates in lockstep with the inventory sprite swap.
