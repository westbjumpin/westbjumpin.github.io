DamageInfo(float, DamageType, GameObject)

Convenience constructor; zeroes hit geometry fields and defaults falloffFactor to 1 (no falloff) and ignoreResistance to false. Use object-initializer syntax to set hitPoint/hitNormal/hitBoneTag/falloffFactor when needed.

falloffFactor

The 0..1 range-falloff factor the firing weapon already baked into amount (1 = no falloff). Lets a hitbox recover the weapon's pre-falloff base damage when AFPS_Hitbox is set to bypass falloff. Sources without falloff leave this at 1.

ignoreResistance

When true, ApplyDamage(DamageInfo) skips the per-DamageType resistance multiplier for this hit. Set by AFPS_Hitbox for body parts flagged to bypass resistance (e.g. headshots).
