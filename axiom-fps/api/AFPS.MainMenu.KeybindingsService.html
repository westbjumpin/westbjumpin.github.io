Class KeybindingsService

Static rebinding facade over the Player action map. Owns the dual-mapping (Primary/Secondary) schema and the persistence format. Does NOT own the InputActionAsset itself — AFPS_InputManager owns it. The Player map is the only rebindable scope; Inventory/UI maps are excluded by design (menu plumbing).

EnsureDualBindings()

Adds a second binding to each rebindable action in each scheme group if one doesn't already exist. Runtime additions are not persisted in the .inputactions asset — they are recreated each session. The (action, scheme, slot) tuple is the stable key used for persistence, not the runtime-generated binding GUID.

FindBindingIndex(InputAction, ControlSchemeSlot, BindingSlot)

Locates the binding index within action.bindings for a given (scheme, slot) pair. Iteration order is asset-stable, so Primary always resolves to the same physical binding across sessions.
