Class AFPS_StatusEffect

ScriptableObject template for a status effect: defines build-up threshold, tick rate, HP/overheal delta, damage type, stack cap, non-HP behaviours, and an optional chained effect. At runtime GiveNewStatusEffect(AFPS_StatusEffect, GameObject) instantiates a StatusEffect from this template.
