Class AFPS_ControlLockStatusBehaviour

Status behaviour that locks the player's controls for the effect's duration — a Stun (lock everything), a Root/Snare (movement only), a Silence-style disarm (firing only), or any mix. Holds a reference-counted lock on AFPS_PlayerControlLock while active and releases it when the effect ends, so overlapping locks compose correctly.

Player-only: it drives the player's movement/camera/weapon systems, so it no-ops on AI (whose "stun" would be an AI-side concern). The control lock is reference-counted, so stacking two stuns and having one expire keeps the player locked until the second ends.
